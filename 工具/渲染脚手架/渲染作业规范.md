# 渲染作业规范（HyperFrames 逐镜出片）

> **用户 2026-10-03 拍板：渲染一律「逐镜渲染 + 逐镜验收」，禁止批量渲完再一起看。**
> 代价实证：批量渲 26 镜时同一处错误被复制到全部镜头 → **26 镜整体返工**；
> 改成逐镜后，9 镜重渲 **9/9 一次通过**。这条优先级高于一切"效率"考虑。

## 这个目录是什么

渲染工作区的**脚手架**：把本目录整个拷进 `项目\<项目名>\渲染工作区\` 即可用。
脚本里的项目根是**自动探测**的（向上找含 `stages\` 的那一层），不用改路径。

| 文件 | 干什么 |
| --- | --- |
| `gen_shots.py` | 由 `bodies\shot_NNN.body.{html,js}` 拼出 `shots\shot_NNN.html`（骨架+公共库+GSAP 注册） |
| `run_render.sh` | 逐镜渲染（HyperFrames），成功判据 = **产物比实现文件新** |
| `check_shot.sh` | 渲完一镜的机检：时长 / 体积 / 抽帧（另三条判据） |

**开工前置**：C 盘 ≥ 2GB；`shots\` 里必须已经有 `gsap.min.js`、`bg.jpg`、`_lib.js`
（从 `D:\HyperFrames\node_modules\gsap\dist\`、项目 `素材\公共素材\`、`bodies\` 各拷一份），
HTML 里一律用相对路径 —— 跨目录 / 走 CDN 会**静默渲成白底**。

## 三条铁律

1. **一次只渲一个镜头**。渲完立刻抽帧自查，过了才渲下一个。
2. **每镜必须过四条验收判据**（缺一条 = 没验）：

   | # | 判据 | 不通过的样子 |
   | --- | --- | --- |
   | ① | **覆盖确认**：新 MP4 写入时间晚于本次渲染开始 | 时间没变 = 渲的是旧文件（EPERM） |
   | ② | **时长** ≈ durationSec + 0.10s，偏差 < 0.12s | 偏差大 = 成片拼片错位 |
   | ③ | **体积**：真画面几十 KB 起步，< 20KB 基本是空画面 | 底图/元素没上去 |
   | ④ | **抽帧肉眼**：约 0.42 / 0.85 处各抽一帧看图，逐元素核对 | 元素缺失、塌左上角、被裁、主体过小 |

3. **不对就改到对为止，再进下一镜**。不允许"先记下来最后一起改" —— 那就是批量。

## 逐镜作业 SOP

```bash
cd "<项目>\渲染工作区"
# ① 写实现：bodies/shot_NNN.body.html + .body.js（自足内联样式，不调未验证的旧库函数）
# ② 拼装 + 语法检查
python gen_shots.py 5
node --check "bodies/shot_$(printf %03d $((10#$5))).body.js"
# ③ 只渲这一镜
bash run_render.sh 5
# ④ 机检（时长/体积/抽帧）
bash check_shot.sh 5
# ⑤ Read 抽帧图 → 肉眼逐元素核对 → 不对回 ②
# ⑥ 过了再进下一镜（重复 ②~⑤）
# ⑦ 全部过完：清 .shot_NNN.hf-transaction-* 残渣、重生成 thumbs、写回包
```

## 零报错的静默失败速查（HyperFrames 专有）

不体检就等着返工 —— 这些坑**一条报错都不会给**，MP4 照常生成、时长体积都正常，只有画面是错的。

| 症状 | 真因 | 怎么防 |
| --- | --- | --- |
| 全屏元素塌在左上角 | `calc()` 括号被 Python `%` 格式化吃掉 → 非法 CSS → 退回 `left:auto` | 改 CSS 不用 `%` 格式化，用 `str.replace` / 函数形式 |
| 元素飞到别处 / 叠在卡片上 | `calc(50%)` 永远相对**自己的定位父容器**，不是相对画面 | 卡片内子元素一律用相对卡片的绝对 px |
| 元素凭空消失 | `<circle>/<line>/<path>/<rect>` 写在 `<div>` 里 → 浏览器静默忽略 | 图形一律用 div + CSS 画 |
| 元素塌在某角 | 只写了 class 没写 `left/top` → `position:static` | 每个定位元素都要有 `left/top` |
| 卡片整体偏移半个身位 | 对"内部用相对坐标"的卡片又叠了 `xPercent/yPercent` | 卡片类不调自身居中 |
| 描边动画不发生 | `drawIn()` 调 `getTotalLength()`，只对 SVG 路径有效 | 改用 `width` / `scaleX` 生长 |
| 画面完全不动（体积正常） | `<video>` 的 `src` 用 JS 赋值，引擎编译期抽帧看到空 src | `src` 写进 HTML 属性（声明式） |
| 渲成白底 / 纯色 | 资源跨目录、走 CDN、中文路径没编码 | 资源拷进 `shots\`，相对路径引用 |
| 报 OK 但产物没变 | 旧 MP4 被占用 → rename EPERM；脚本只判"文件存在" | 成功判据用 `mp4 -nt html`；先挪走旧文件 |
| 整批漏渲 008/009 | `printf "%03d" 008` 把 008 当八进制 | `printf "%03d" "$((10#$n))"` |

## 画面用词

**画面上的每一处文字都要跟台词原意对一遍。** 转写稿（ASR）常有同音错字 ——
实证：「糊粥总比没粥好」被转写成「梅州总比胡州好」。画面里的错字是观众**直接看见**的，
比口播听错严重得多，以**语义通顺**为准，别照抄转写稿。

## 单镜失败怎么办

先查是不是旧文件被占用（EPERM）：`mv shot_NNN.mp4 shot_NNN.stuck.mp4` 挪走再重渲。
确实渲不出来才跳过并记录 —— **绝不把旧产物当成功报上去**。
