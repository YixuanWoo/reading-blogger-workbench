## 一、画面规格（已定版，硬约束）

| 项         | 规定                                                                                                             |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| 画幅        | 横屏 16:9 · 1920×1080 · 30fps（不做竖屏）                                                                              |
| 底图        | 每项目统一铺 `项目\<项目名>\素材\公共素材\grid-bg-deep-blue-grid.jpg`（深蓝底 + 细网格线）                                               |
| 叠放关系      | 画面元素一律**叠在底图之上**：卡片 / 细线框 / 文字块，四周留白让网格透出；**禁止**白底 / 纯黑底大色块、禁止任何图片铺满全屏                                         |
| 文字色板      | 浅色系：米白 `#f3ecdc` / 亮金 `#f0d68a` / 浅蓝 —— 深蓝底上深色字看不清                                                             |
| 网格 = 设计语言 | 元素沿网格对齐、线条沿网格走，网格是画面的一部分不是背景噪音                                                                                 |
| 渲染引擎      | HyperFrames（HTML/CSS/GSAP → 逐镜 MP4）。动效必须能用网页技术实现：位移 / 缩放 / 描边动画 / 逐字出现 / 数字滚动 / Ken Burns；**禁止**实拍航拍、真人出镜、三维建模 |

## 二、已沉淀的硬规则（每条都来自真实返工，别再犯）

1. **"不要字幕" ≠ "画面不要文字"**（2026-09-30 事故，219 镜重渲）。  
   禁的只是底部跟着口播滚的白色字幕条；**每个镜头画面里必须有至少一处文字锚点**  
   （关键词 / 数字 / 标题 / 高亮短语）。一个文字都没有的镜头 = 废镜头。
2. **长镜头（>12s）必须多阶段动起来**：关键词随口播依次高亮、要点逐条落下、数字跳数、  
   长句拆 2~3 个视觉层次。整段字幕顶在屏幕中间不动是最差解。
3. **动效要带可执行参数感**：写清"第几秒出现什么、怎么变、变到什么程度"  
   （例："卡片从下方 40px 上浮 + 淡入，0.6 秒完成"），不写"优雅地出现"。
4. **每镜渲染时长 = 该镜音频时长 + 安全尾（定格、不放新内容）**。  
   关键内容的落点（最后一个词、最后一个数）必须在音频时长之内收住，否则被裁。
5. **插片（无口播的镜头）**：不替它编台词；画面反而要做满 —— 没有声音时画面就是全部内容。  
   文字锚点规则对插片同样有效。默认静音；开了「素材原声」的按音量字段走，不写死 0。
6. **画面文字以语义通顺为准，别照抄转写稿**（ASR 同音错字实证：「糊粥总比没粥好」→「梅州总比胡州好」）。
7. **网络图片**：image 字段写"什么样的图（主体+风格+用途）+ 用什么动效展示"，不是文件名；
   优先选通用好搜的概念图；搜不到就降级成纯排版镜头，绝不为一张图卡住流水线。
8. **整体风格轻松愉快，文字出场/离场动效丰富**；转场 = 旧元素动效退场 → 新元素动效出场，
   不允许单调硬跳。字体不指定，画面合理即可。（翊瑄拍板 2026-10-04）
9. **金句卡**：圆角卡片式，颜色与深蓝网格底图协调，版式不固定。（翊瑄拍板 2026-10-04）
10. **信息密度双模式**（翊瑄拍板 2026-10-04）：科普 / 数据 / 理工 / 心理类 → 信息呈现密集、
    带科技感、画布吃满（未必真多，呈现要密）；文史 / 文学类 → 简约克制。分镜时先判内容类型再定密度。
11. **节奏：任何画面静止不超过 5 秒**（收紧原">12s 必须动"）；镜头必须动起来，
    长镜的动效要持续演进、跟着台词变化，不许呆板挂着。（翊瑄拍板 2026-10-04）
12. **角标**：右下角带"翊瑄在潜水"角标，要足够小、不抢主体。（翊瑄拍板 2026-10-04）
13. **声音**：音效要短促、音量与口播相当；BGM 在有人声口播时必须闪避（ducking），不干扰说话。
    ★ 现状注记：渲染链路暂无 BGM/音效通路（成片音轨 = 口播重建 + 插片原声），
    本条先作为标准预留，待组接/录音台支持后生效。（翊瑄拍板 2026-10-04）
14. **元素不得互相遮挡重叠**，布局留最小间距；画面**只放设计要求的元素**，
    不加设计之外的装饰物；**动效时机忠实于口播**——motion 写了第几秒出现就必须那一刻出现。
    （均来自 2026-10-03 上期 21 条镜头意见回流）

## 三、品味待填区 → ✅ 已全部拍板（2026-10-04），标准已收进 §二

> 下面是拍板原文留档；以后有新的口味判断，继续记在这里，我定期收拢进 §二。

- 转场风格：动效退场，然后新的元素动效出场。动效不能太单调（→ §二 8）
- 金句卡：不固定，但要是圆角卡片式，颜色与背景协调（→ §二 9）
- 信息密度：按内容定——科普/科学/数据/理工/心理类拉满、科技感、画布吃满；文史文学类简约克制（→ §二 10）
- 每镜节奏：固定画面不超过 5 秒，必须动，长镜动效持续吃满、跟台词变化（→ §二 11）
- 字体：不指定，画面合理即可（→ §二 8）
- 角标：右下角"翊瑄在潜水"，要足够小（→ §二 12）
- 音乐/音效：AI 自定；音效短、与口播音量差不多；BGM 人声时闪避（→ §二 13，待通路实现）
