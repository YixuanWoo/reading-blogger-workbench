## 二、怎么写稿（核心习惯）

**写作台现在是一整篇 Markdown。** 你没有"段落"这个概念，你写的就是一篇文档：

- **回车只是换行**，不切任何东西 —— 想分段就多按一下回车，仅此而已。
- **标题表达结构**：用 `#`、`##`、`###`…（最多 6 级）写标题。
- **写的时候**：
  - 左侧**目录**自动按标题生成，点标题跳到对应位置；
  - 底部状态栏实时显示 **字数 / 句数 / 行数 / 标题数**；
  - 右上角 **眼睛图标按钮**（展开预览）——点了才在右侧打开渲染面板看成品效果（**不默认开**）；
    预览展开后，**中间那条细线可以左右拖动**，调整「原文 / 预览」的显示比例。

> ★ **标题用标准语法：`#` 后面必须有空格** —— 写 `# 第三方`，不要写 `#第三方`。
> 这是标准 Markdown（CommonMark）的规矩，GitHub / Obsidian / Typora / VS Code 全都要空格；
> 写作台也严格按标准来。养成好习惯，稿子拿到任何环境都能通。

### 支持的 Markdown

| 语法 | 怎么写 | 效果 |
|---|---|---|
| 标题 | `# 一级` / `## 二级` / `### 三级` | 变大字，且进左侧目录 |
| 粗体 | `**重点**` | 加粗 |
| 斜体 | `*强调*` | 斜体 |
| 删除线 | `~~删掉~~` | 划线 |
| 行内代码 | `` `var x=1` `` | 等宽小字底纹 |
| 代码块 | 三个反引号包裹 | 等宽块，深色底纹 |
| 无序列表 | `- 项` / `* 项` | 圆点列表 |
| 有序列表 | `1. 项` / `2. 项` | 数字列表 |
| 引用 | `> 引用` | 左侧竖线引用块 |
| 分割线 | `---` | 横线 |
| 链接 | `[文字](网址)` | 可点击链接 |

> 表格、图片、数学公式**本期不渲染**，会原样显示成文本（独立成软件那期再补）。

## 三、保存

**还是那一个入口，没变**：

- 顶栏「保存项目」/ `Ctrl+S` / **20 秒自动保存** —— 稿子一并落盘。
- 存进的是 `<项目>\script.md`（**无 BOM**，你可以在 Obsidian 直接打开继续写）。

### 丢了怎么办 / 未保存改动

- **切走再切回**：有未保存改动时会问「存 / 弃 / 取消」，绝不默默覆盖（V1.10.4 的老规矩还在）。
- **退出工作台**：稿子有改动没保存会拦你一下，问要不要先存。

### 和 Obsidian 的关系

**单向、显式**：打开写作台时读一次 `script.md`，保存时整篇写回。
程序开着时你在 Obsidian 改了 → 不理会，**下次打开才读到**。别在两边同时改（会互相覆盖）。

## 四、一句话提醒

- 想重新生成目录？只要写了/改了标题，目录**自动跟着变**，不用手动刷。
- 稿子写完记得**存一次**（或等 20 秒自动存），然后去① 转写。

## 五、录音去哪了

旧版"回车切段 + 逐段录音"的整套（段落块、永久 ID、audio/takes、待重录）**在 V1.11.0 已整体删除**。
录音是将来独立写作软件那期的事，届时会按**标题/行范围**重新挂，与现在的写作台无关。
