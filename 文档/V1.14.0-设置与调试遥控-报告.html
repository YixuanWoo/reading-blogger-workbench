顶栏多了两个按钮，还给工作台装上了「记录仪 + 遥控手」

2026-10-15　·　编译 0 警告 0 错误　·　新程序已发布到 D:\工作台\工作台.exe

这次你要的三件事都做好了：顶栏按钮、设置窗、debug 模式。
其中 debug 模式最要紧 —— 它不只是"记日志"， 而是让我能像真人一样点你的软件、读你的软件。 以后你让我帮你测功能，我不用再截图、也不用写一堆测试代码， 开起来点一遍就行。另外复盘页已经搬到一级菜单了。

1顶栏多了两个按钮

就在左上角，跟一般软件那样排着

文件 ▾设置 　← 就在这一排
「文件 ▾」点开有三项：
　· 导入外部项目… —— 先灰着（你要的未来功能，位置先占住）
　· 打开项目根目录
　· 打开日志文件夹

★ 一个技术上的小讲究：Windows 的下拉菜单**默认只有右键才弹**。 我特意写成"左键点一下也弹" —— 不然就不像"一般软件"了。

2设置窗：三类，都在一个地方了

左边选类别，右边填；底下「保存设置」

类别里面有什么为什么放这儿
大模型配置 接口地址 / 密钥 / 模型名 / 是否流式 + 一个「测试连接」 ★ 你说的"**API 配置不用再在项目面板里进行了**" —— 已经从那边搬过来了
路径配置 项目根目录 · ffmpeg · 素材模板 · 渲染引擎 · 模板库 · 归档盘 · 转写兜底 ★ 你说的"**不用把路径写死在代码里**" —— 每个格子下面还写着"现在实际用的是哪个"，免得改了个名字其实没生效
调试 开关 · 端口 · 是否落盘 · 状态 · 「打开日志文件夹」 见下一节

★ 一句话安心：你没动过设置的话，软件的走法跟以前一模一样 —— 设置只是把原本藏在代码里的"中间那层"露出来给改，改了才生效。

3★ 调试模式：给软件装「记录仪」+「遥控手」

这是这次改动里最有分量的一块

打个比方：以前的软件像一个黑盒子——你在外面看它亮没亮，但不知道里面发生了什么； 我想帮你查，只能拍张照片回来猜。现在不一样了：

📹 记录仪（自动记账）

  • 谁被点了（哪个按钮、上面写的什么字）
  • 哪个框打了字、哪个下拉换了项
  • 切到了哪一页、哪个项目
  • 底部状态栏说了什么（比如"已保存一条数据"）
  • 文件增 / 改 / 删 / 改名

🖐 遥控手（直接操作）

  • 我能点软件里任何一个按钮
  • 我能往输入框打字、勾选、拨下拉
  • 我能跳到任意一页
  • 我能读屏幕上写的字（不用截图）
  • 弹出来的确认框，我也能读到内容并点掉

以前 / 现在，对比一下就懂：

以前

  • 想验一个按钮 → 我得截图看，或者写一段专门的测试代码
  • 点完发生了什么 → 看不见，只能猜
  • 一个流程要你手动点好几步给我看

现在

  • 开起来，我直接点，点完直接读账本
  • 每一步的结果（成功 / 失败 / 弹了什么框）都留痕
  • 一个流程我几十秒自己跑完，还顺手附证据

★ 它不是"偷偷"在跑：默认是关的，而且只连本机（外网 / 局域网都连不进来）， 要开得你自己去 设置 → 调试 里拨一下。

4复盘：搬到一级了

从"项目里第 6 步"挪到"最外面那一级"—— 就像你要的那样

左边菜单（一级）：
灵感　·　进行中　·　已归档　·　复盘　← 搬这儿了

★ 一级页面没有"当前打开的项目"这个概念，而复盘数据是长在项目里的， 所以我在页面顶上加了一个「看哪个项目」下拉框 —— 选谁看谁，默认帮你选"刚打开的那个"。

⚠️ 一个要提前说清的取舍：因为复盘变成一级页了，当你正开着某个项目时， 左边菜单里就看不到「复盘」了（它不在项目里了）。 想看的话先点一下 「← 全部项目」 回到一级，再点「复盘」。 这不是坏了，是"级别"带来的必然结果 —— 将来做双类型时可以把这一步做得更顺。

你说的大工程（项目复盘 / 账号复盘）这次没动，按你的要求先写了待办： 工作台\文档\复盘页-改造待办.md / .html（含开工前要你先拍板的四条）。
