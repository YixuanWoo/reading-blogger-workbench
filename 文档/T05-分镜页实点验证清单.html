照着点（顺序别乱）

1
进 ③ 分镜页 → 确认切法亮在「语义合并」→ 点「生成镜头切分」
左边导航进第 ③ 分镜 页。工具条最上面那排，「一句一镜 / 固定节奏 / 语义合并」三个圆点， 应该亮在语义合并（新项目默认）。右边显示 块长 5 ~ 9 秒/块。
然后点左边的 生成镜头切分。
右边卡片流立刻铺出镜头卡（几十张）；状态栏出现 「已切出 N 个镜头」； 工具条下面那行提示显示切法说明（“语义合并：贪心把句子并成 5~9 秒的块”）。 —— 若这个按钮是灰的，说明剪辑决策没加载，回①跑一次粗剪再来。
2
点一张卡的卡头选中它 → 点卡上「合并▾」
在任意一张镜头卡的空白处 点一下卡头（会选中，左缘竖条变蓝）。 先记住这张卡是第几镜、下一镜是第几。
然后点这张卡右上角的 合并▾（等价于工具条的 合并选中镜+下一镜）。
瞬间完成（不等 Agent）。卡片总数 少 1 张；被合并的那张卡索引旁冒出橙色的 ✎， 左缘竖条变橙；工具条右侧出现 「· 1 镜手动调过」。
若这两镜已经有分镜设计 → 会先弹一个框问“原来那份设计怎么办”（拼接保留 / 清空 / 取消），选任一个都行。
3
点刚才那张卡的「拆分」
还是选中那张卡，点它右上角的 拆分（等价于工具条的 拆分选中镜）。 它会在最接近这镜中点的那句话说完之后切开 —— 没有“按时间切”这种选项（那是伪选项，已删）。
瞬间变两张，前后两段时长之和 = 原来那一镜。两张都带 ✎、都算“手动调过”。
若这镜只有一句 → 状态栏提示“这一镜只有一句，没法按句子拆”；若原本有设计 → 会弹框提示设计只覆盖前半并标「待复核」。
4
最后看交接闸门那一条（卡片流上方）
那条写着「下游当前使用：…」，同一条右边是「应用到下游」按钮。它永远只报已交接版。
点生成切分之前，这条应写：「下游当前使用：镜头表 55 镜 · 已交接于 …」， 提示 「草稿与已交接版一致 —— 下游现在就用这一份（55 镜）。改动后记得点一次交接。」，按钮显示 ✓ 已在生效（灰）。
做过第 2/3 步之后，提示应变成 「草稿 N 镜（有还没交下去的改动）· 成片已经出过 —— 交接后还需要到第⑤步重新组接」， 按钮变成可点的 应用到下游。
—— 这一变，就证明闸门是活的：拆/合只改草稿，点「应用到下游」才算交下去。

判据速查：看到什么 = 什么结论

现象结论
点「生成镜头切分」→ 卡片流出块表，且块数 < 一句一镜的句数✔ 语义合并生效（贪心成组，5~9 秒/块）
点「合并」→ 瞬成、少一镜、出现 ✎ 与橙条✔ 合并 + Edited 标记都对
点「拆分」→ 瞬成、多一镜、切点在句末✔ 按句边界拆分生效
工具条出现「· N 镜手动调过」✔ ✎ 计数与刷新逻辑正常
交接条仍写“下游当前使用：55 镜”✔ 闸门正确：草稿改了 ≠ 已交下去
按钮点下去卡住 / 要等 / 弹 Agent 相关提示✘ 有 bug —— 这三个动作应当 0 延迟、纯本地
⚠ 这一轮千万别点的两个按钮：
· 「应用到下游」 —— 那是 T-17 要验的东西。一点就会把草稿转正、重排镜号、把 51 个产物改名。验 T-05 用不着，先别碰。
